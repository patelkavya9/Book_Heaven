Book Haven – E-Book Web Platform
This project is a frontend web-based e-book platform developed using HTML, CSS, and JavaScript. It allows users to browse books, view details, and access reading content through a structured and interactive interface. The system includes multiple pages such as homepage, book pages, login/signup, and help/FAQ sections.

Prerequisites
Web browser (Chrome, Edge, etc.)
VS Code or any code editor (optional)
Live Server extension (optional)

Setup Instructions
Clone the repository:
git clone <your-repo-link>

Open the project folder in your code editor

Open home.html directly in a browser
or use Live Server for better experience

Features
Homepage with image slider and featured books section
Multiple book pages with description and reading option
Login and signup system using localStorage
Navigation menu with dropdown user interface
FAQ/help section with interactive toggling
Responsive layout and clean UI design
